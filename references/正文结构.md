# 正文结构

## 一、通用三段式

所有函的正文均遵循三段式结构：

```
一、缘由（为什么发函/复函）
二、事项（函的核心内容）
三、结语（固定用语）
```

## 二、14 种函的结构变体

### 1. 商洽函
- 缘由：协商目的和背景
- 事项：协商事项分条列述，每条写明请求内容和所需配合
- 结语：请予支持/盼复

### 2. 询问函
- 缘由：询问原因
- 事项：具体问题列表，每个问题写明需要了解的内容
- 结语：请函复/盼复

### 3. 请批函
- 缘由：引用依据+简述背景
- 事项：请求事项+理由和依据+相关条件
- 结语：请予审批/妥否请函复

### 4. 告知函
- 缘由：告知原因
- 事项：通报事项（不需对方回复）
- 结语：特此函告/特此函达

### 5. 征求意见函（分定向型/公开型）
- 缘由：征求意见的文件名称、目的和依据
- 事项（定向）：现征求贵单位意见+反馈时限+逾期条款+反馈方式
- 事项（公开）：现公开征求意见+"各机关团体……均可提出"+截止时间+反馈方式
- 结语（定向）：请于X日前反馈，逾期视为无意见 / 请研究后函复
- 结语（公开）：无专门结语（以联系人信息块收束），或"感谢支持！"
- 附件：征求意见稿（定向型建议附起草说明；公开型可注明网上查阅）

### 6. 邀请函
- 缘由：活动名称+目的
- 事项：时间+地点+参加要求+其他事项
- 结语：敬请莅临/恭请参加

### 7. 催办函
- 缘由：引述此前函件（日期+字号+摘要）
- 事项：未收到回复+催促理由+新时限
- 结语：请抓紧办理

### 8. 协调函
- 缘由：协调目的和依据
- 事项：协调背景+各方分工（逐单位列明）+协调机制+反馈要求
- 结语：请按分工落实/特此函商

### 9. 协办/协助函
- 缘由：主办事宜和需要协办的原因
- 事项：主办事宜+协办请求（逐条列明）+协办范围+反馈方式
- 结语：请予协助为盼

### 10. 一般答复函
- 缘由：引来文标题+字号+"收悉。经研究，现函复如下"
- 事项：逐项答复，结论置前
- 结语：特此函复

### 11. 批准函
- 缘由：引来文标题+字号+"收悉。经研究，现函复如下"
- 事项：批准结论+条件/要求
- 结语：特此函复

### 12. 提案答复函
- 缘由：引提案编号+主题+"收悉。经商……，现答复如下"
- 事项：逐项对应提案建议，每条先给结论再给依据和措施
- 结语：感谢您对……的关心和支持

### 13. 建议答复函
- 缘由：引建议编号+主题+"收悉。经商……，现答复如下"
- 事项：逐项对应建议，每条先给结论再给依据和措施
- 结语：感谢您对……的关心和支持

### 14. 转办函/交办函
- 缘由：说明转办来源
- 事项：转办事项+办理要求+注意事项
- 结语：请办理后函告结果

## 三、篇幅控制

| 函类型 | 建议篇幅 |
|---|---|
| 商洽/询问/告知/催办/邀请/协办/转办 | 300-800 字 |
| 请批/协调/征求意见 | 500-1000 字 |
| 一般答复/批准 | 300-1000 字 |
| 提案/建议答复 | 1000-3000 字 |

## 四、复函引据规则

复函必须引用来函/来文标题和发文字号：
- "贵单位《关于……的函》（X函〔20XX〕X号）收悉。"
- "你们关于……的来函收悉。"
- "您提出的关于……的提案（第XXXX号）收悉。"

不得上来就给结论而不交代答复的是哪份来文。
