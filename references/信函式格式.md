# 信函式格式

## 一、信函式 vs 文件式

| 要素 | 信函式（函） | 文件式（通知/报告等） |
|---|---|---|
| 发文机关标志 | 机关全称或简称，不加"文件"二字 | 机关名 + "文件" |
| 红色分隔线 | 武文线（上粗下细双线） | 单线 |
| 发文字号位置 | 第一条双线下右端顶格 | 版头下方居中或左端 |
| 首页页码 | 不显示 | 显示 |
| 标题 | 发文机关 + 事由 + "函"/"复函" | 发文机关 + 事由 + 文种 |

## 二、信函式版头规格

| 要素 | 规格 |
|---|---|
| 发文机关标志 | 居中，上边缘至上页边距 30mm，红色小标宋体 |
| 武文线 | 距发文机关标志下边缘 4mm，上粗下细双线 |
| 发文字号 | 第一条双线下右端顶格，3 号仿宋体 |
| 标题 | 武文线下空一行居中，2 号小标宋体 |
| 主送机关 | 标题下空一行顶格，3 号仿宋体，全角冒号 |

## 三、通用格式参数

引用公文格式修订.skill 的 references，本技能不重复：
- 纸张：A4
- 页边距：37/35/28/26mm
- 行距：固定值 28.95pt
- 首行缩进：2 字符
- 正文字体：仿宋_GB2312 三号
- 标题字体：方正小标宋简体 二号

## 四、函的格式注意事项

1. 函使用信函式版头，不使用文件式版头。
2. 武文线（双线）是信函式的标志，不能用单线替代。
3. 首页不编页码，从第 2 页起编。
4. 附注（联系人信息）放在成文日期下一行，左空 2 字，加圆括号。
5. 函的篇幅通常较短，一般不超过 2 页。

## 五、格式终审联动

起草完成后，可建议用户调用 `$document-format-skill` 做格式终审。本技能不重复格式修订能力。
