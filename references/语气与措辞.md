# 语气与措辞

## 一、平行文语气原则

函是平行文，语气必须**平等、礼貌、直接**：
- 不用命令、指示语气（"务必""必须""严禁""请遵照执行"）
- 不用过于谦卑的措辞（"恳请贵单位百忙之中予以关注"）
- 不用空泛套话（"高度重视""精心组织""扎实推进"）
- 直陈其事，不绕弯子

## 二、称谓规范

| 场景 | 称谓 |
|---|---|
| 去函对收文机关 | 贵单位 / 贵办 / 贵厅 / 贵局 / 贵委 |
| 复函对来文机关 | 你单位 / 你厅 / 你局 / 你委 |
| 提案/建议答复 | 您 |

## 三、期请用语

| 强度 | 用语 | 适用场景 |
|---|---|---|
| 强 | 请 / 拟请 | 请批函、催办函 |
| 中 | 商请 / 恳请 | 商洽函、协办函 |
| 弱 | 敬请 / 盼 / 望 / 希 | 邀请函、询问函 |

## 四、禁用措辞表

| 禁用 | 原因 | 替代 |
|---|---|---|
| 请批示 / 请批准 | 请示用语 | 请函复 / 请予审批 |
| 当否，请批示 | 请示用语 | 妥否，请函复 |
| 特此通知 | 通知用语 | 特此函告 |
| 此致敬礼 | 书信用语 | 特此函复 |
| 请遵照执行 | 命令语气 | 请予支持 / 请研究函复 |
| 务必 / 必须 / 严禁 | 命令语气 | 请 / 拟请 / 商请 |
| 特此报告 | 报告用语 | 特此函告 |
| 让我们携手共进 | AI 套话 | 删除 |
| 具有重要意义 | AI 套话 | 删除或替换为具体意义 |
| 高度重视、精心组织、扎实推进 | 三连套话 | 替换为具体动作 |
| 取得实效 | AI 万能结尾 | 替换为具体成果 |
| 为进一步推动…… | AI 万能开头 | 直接写目的 |
