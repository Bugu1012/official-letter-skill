# 文种辨析

## 一、核心判断标准

函是**唯一的平行文种**。判断是否应使用函，核心看**有无隶属关系**：

- 有隶属关系 + 上行 → 请示/报告
- 有隶属关系 + 下行 → 通知/批复/决定
- 无隶属关系 → 函

## 二、六组易混辨析

### 1. 函 vs 请示

| 维度 | 函（请批函） | 请示 |
|---|---|---|
| 行文方向 | 平行 | 上行 |
| 对象关系 | 不相隶属 | 有隶属关系的上级 |
| 结语 | "请予审批""妥否，请函复" | "妥否，请批示""当否，请批示" |
| 最常见误用 | 向无隶属关系的主管部门发请示 | — |

### 2. 函 vs 通知

| 维度 | 函（告知函） | 通知 |
|---|---|---|
| 行文方向 | 平行 | 下行 |
| 语气 | 告知、协商 | 要求执行 |
| 最常见误用 | 向不相隶属机关发通知 | — |

### 3. 函 vs 报告

| 维度 | 函 | 报告 |
|---|---|---|
| 行文方向 | 平行 | 上行 |
| 目的 | 商洽/询问/答复/请批 | 汇报工作/反映情况 |
| 最常见误用 | 向不相隶属机关发报告 | — |

### 4. 函（复函） vs 批复

| 维度 | 复函 | 批复 |
|---|---|---|
| 行文方向 | 平行 | 下行 |
| 对象关系 | 不相隶属 | 上级对下级 |
| 来文 | 来函 | 请示 |
| 语气 | 平等答复 | 可带权威口吻 |
| 最常见误用 | 答复不相隶属机关时用批复 | — |

### 5. 征求意见函 vs 通知

| 维度 | 征求意见函 | 通知 |
|---|---|---|
| 行文方向 | 平行 | 下行 |
| 目的 | 征询意见 | 要求执行/周知 |
| 最常见误用 | 向不相隶属机关征求意见时发通知 | — |

### 6. 请批函 vs 请示

| 维度 | 请批函 | 请示 |
|---|---|---|
| 对象 | 无隶属关系的主管部门 | 有隶属关系的上级 |
| 判断方法 | 查组织关系：是否在同一系统内有上下级关系 | — |
| 最常见误用 | 最易混淆，核心看有无隶属关系 | — |

## 三、判断树

```
用户要写公文
  │
  ├─ 对象是上级（有隶属关系）？
  │   ├─ 是 → 请求批准/指示？ → 请示
  │   │       汇报工作/反映情况？ → 报告
  │   └─ 否 → 对象是下级（有隶属关系）？
  │       ├─ 是 → 部署工作/要求执行？ → 通知
  │       │       答复下级请示？ → 批复
  │       └─ 否 → 不相隶属 → 函
  │           ├─ 主动发出？ → 去函（9 种之一）
  │           └─ 答复来函？ → 复函（4 种之一）
```

## 四、质询式澄清

当隶属关系不清时，问："贵单位与对方单位是否存在上下级隶属关系？"

- 有隶属关系 + 上行 → 不是函，建议用请示/报告
- 有隶属关系 + 下行 → 不是函，建议用通知/批复
- 无隶属关系 → 确认使用函
