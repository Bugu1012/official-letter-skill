# 撰写思路

> 来源：zhaohui-yang/official-document-drafting 函 spec + 回复函 spec

## 一、起笔定式

| 函类型 | 起笔句式 |
|---|---|
| 商洽函 | "为……，现商请你们协助……""为……，现将有关事项函商如下" |
| 询问函 | "因……工作需要，现就有关事项函询如下" |
| 答复函 | "你们关于……的来函收悉。经……同意，现函复如下" |
| 请批函 | "根据……，现就……事项函请审批" |
| 告知函 | "因……，现将有关事项函告如下" |
| 征求意见函（定向） | "为……，我部起草了《……（征求意见稿）》，现征求贵单位意见" |`n| 征求意见函（公开） | "为……，我部组织修订了《……》，形成了《……（修订征求意见稿）》，现公开征求意见" |
| 邀请函 | "兹定于〔时间〕在〔地点〕举办〔活动〕，诚邀贵单位……" |
| 催办函 | "关于〔事项〕，此前已函商/函告……，至今未收到回复" |
| 协调函 | "为……，根据……，现就〔协调事项〕函商各单位如下" |
| 协办函 | "根据……，我局正在办理〔主办事宜〕，因……，需贵单位协助〔协办事项〕" |
| 转办函 | "现将〔来源〕转来的〔事项〕转送你单位办理" |
| 提案答复 | "您提出的关于……的提案收悉。经商……，现答复如下" |
| 建议答复 | "您提出的关于……的建议收悉。经商……，现答复如下" |
| 批准函 | "你单位《关于……的函》（〔字号〕）收悉。经研究，现函复如下" |

## 二、谋篇原则

- 一函一事，事项清楚
- 商洽/请批型：请求事项、所需配合、反馈方式与时限写清
- 答复/复函型：答复结论置前，再分条说明，不让对方通篇寻找结论
- 复函必须逐项对应来函，"有问必答、对应清楚"
- 征求意见函必须写明反馈时限和反馈方式
- 协调函必须逐单位列明分工
- 协办函必须写明协办范围

## 三、主送规则

- 可为单一机关，也可为多行平行/不相隶属机关序列
- 部委商洽函/协调函常并列多家收文机关，按从中央到地方、从主到次排列
- 同级别同类机关用顿号，不同类别用逗号

## 四、语域控制

- 身份平等，称"贵单位／你们"，既不居高临下也不仰视
- 商洽用"商请""拟请"，不用命令式部署口吻
- 复函对来文机关称"你厅/你局/你单位"，平行不相隶属称"贵单位"
- 协调函牵头方有组织权威，但仍用"函商""请"

## 五、要素分层

| 层级 | 要素 |
|---|---|
| 必备 | 标题、主送单位、事项缘由、主要意见、落款 |
| 常见 | 配合事项、来函或发函背景、具体协商事项 |
| 条件项 | 反馈时限、附件 |
| 项目自定义 | 附注联系人（默认保留，用户要求删除时去掉） |

## 六、常见误区

- 把本应用函的事项升格为请示或通知
- 一函多事
- 答复型把结论埋在文末让对方通篇寻找
- 漏引来文标题与发文字号（复函）
- 答非所问或超出来文范围答复（复函）
- 征求意见函未写反馈时限
- 催办函使用命令语气
- 协调函分工模糊（"请各单位配合"而不说明谁做什么）
- 协办函协办范围不清
