# 函语言自然化

本文件用于在事由台账锁定、函类型确认、正文结构完成后，对函件作自然、简明、平实的语言处理。目标是消除机械套话和 AI 式平均节奏，不是把正式公函改成个人文章，也不是为了"像人写的"而牺牲规范性和可执行性。

> 方法来源：[blader/humanizer](https://github.com/blader/humanizer)、[op741lst/Humanizer-zh](https://github.com/op741lst/Humanizer-zh)、[onlyLT/wow-gongwen-writing](https://github.com/onlyLT/wow-gongwen-writing)，经会议纪要技能适配后再次适配函场景。详见同系列 [Bugu1012/Meeting-minutes](https://github.com/Bugu1012/Meeting-minutes) `references/自然化方法来源与适配.md`。

## 适用边界

适用于：
- 事由台账已锁定、函类型已确认、正文三段式已搭好的函件初稿。
- 语言重复、生硬、口号化或模板痕迹明显的函件草稿。
- 需要在不改变公文函语体的前提下压缩套话、改善衔接的稿件。

不适用于：
- 尚未建立事由台账、尚未确认函类型的原始需求。
- 需要通过"润色"补足缺失事项、依据、时限或主送机关的稿件。
- 事实不清时使用 `〔待补〕`/`〔待确认〕` 标注，不用更顺的句子掩盖缺口。

**语言自然化不是事实修复。**

## 处理次序

严格按以下顺序：

1. **锁定要素**：从事由台账标出不可变内容（见下节）。
2. **扫描机械表达**：查找函件特有的套话模式（见§常见机械表达）。
3. **初改**：保留全部有证据信息，允许合并或拆分句段。
4. **自审**：检查残留机械模式和新增事实。
5. **二改**：只处理自审命中项，不做随机换词。
6. **复核**：从改写稿回事由台账核锁定项。

## 必须锁定的内容

以下内容不得在语言处理时增删、改强、改弱或替换：

- 发函机关、主送机关全称或规范简称。
- 来函标题、发文字号（复函引据）。
- 文件名称、项目名称、法规名称和其他专名。
- 日期、数量、金额、比例、序号。
- 反馈时限、截止日期。
- "同意、不同意、原则同意、暂缓、不予"等结论词。
- "不得、严禁、仅限、至少、经……后"等限定词。
- 联系人、电话、邮箱、地址。
- `〔待补〕`、`〔待确认〕` 标记。

## 函件常见机械表达

| 模式 | 示例 | 处理 |
|---|---|---|
| 万能意义铺垫 | "为进一步推动……的发展，提升……水平" | 删除或替换为具体依据 |
| 空泛背景堆叠 | "当前，……面临新形势新任务新要求" | 删除，直入事项 |
| 三段式包装 | "高度重视……切实加强……确保……" | 改为具体主体+动作+时限 |
| 同义反复 | "认真研究、深入分析、充分论证" | 保留一个 |
| 万能结尾 | "为……贡献力量""共同推动……迈上新台阶" | 删除，以规范结语收束 |
| 模糊归因 | "有关方面认为""普遍认为" | 恢复具体主体或删除 |
| 过度礼貌 | "恳请贵单位百忙之中……" | 改为"请贵单位……" |
| AI 高频词 | "赋能、抓手、闭环、底层逻辑、颗粒度" | 替换为公文用语 |
| 机械排比 | 强凑三项对仗 | 有几项写几项 |

## 函件自然化原则

### 信息保真
自然化可以改变句子长短、语序和段落组合，但不能改变锁定内容。

### 表达具体
- 有真实依据时写依据（"根据《……》"），不写空泛意义。
- 有具体事项时直陈事项，不先宣告其"重要"。
- 同一信息只说一次。

### 节奏自然
- 函件篇幅短（300-1000字），不需要"起承转合"。
- 缘由 1-2 句，事项逐条列明，结语 1 句。
- 不强凑对仗，不机械排比。

### 语体稳定
- 平行、礼貌、直接。
- 不命令、不卑微、不宣传。
- 称谓一致（"贵单位"或"你局"，不混用）。

## 禁止采用的做法

- 为表现"有人味"加入个人观点、情绪、幽默或第一人称。
- 用故事、比喻、金句、反问增强感染力。
- 通过随机换词、打乱结构制造所谓人类节奏。
- 为降低 AI 检测概率而牺牲规范和准确。
- 补写用户未提供的事实、数据或文件号。
- 把"请予支持"改成更"有温度"的个人化表达。

**函件的自然感来自事项具体、结构清楚、用词稳定、语气得体，不来自个人化表达。**

## 改前/改后对照

| 改前 | 问题 | 改后 |
|---|---|---|
| 为深入贯彻落实党的二十大精神，进一步推动我市营商环境优化升级，持续提升市场主体获得感和满意度，我局拟定了《……》。 | 万能意义铺垫+空泛目标堆叠 | 根据《……》（〔字号〕）要求，我局拟定了《……》。 |
| 贵单位在百忙之中拨冗审阅，我局深感荣幸。恳请贵单位组织精干力量，认真研究，提出宝贵意见。 | 过度礼貌+空泛请求 | 请贵单位于〔日期〕前将修改意见反馈我局。 |
| 让我们携手共进，为推动……事业高质量发展贡献力量！ | 宣传性结尾+感叹号 | 删除。以"特此函达"或"请予支持为盼"收束。 |
| 我局高度重视、认真研究、深入分析、充分论证，认为该方案切实可行。 | 同义反复+空泛结论 | 经研究，我局认为该方案可行，具体意见如下： |

## 两遍审校

**第一遍（初改后自审）**：
1. 哪些句段仍有空泛铺垫、机械排比或万能结尾？
2. 改写是否新增了用户未提供的事实或依据？
3. 改写是否删掉或弱化了时限、限定词、否定或结论词？
4. 称谓是否一致？结语是否匹配函类型？

**第二遍**：只修改自审命中项。没有问题的句子不动。

## 硬性退回条件

出现以下任一情形，自然化不通过：
- 新增用户未提供的事实、数据、文件号或依据。
- 删除或弱化反馈时限、逾期条款、限定词。
- 改变结论词（同意→原则同意，不予→暂缓）。
- 错配主送机关、联系人或来函引据。
- 把〔待补〕/〔待确认〕写成确定内容。
- 结语与函类型不匹配。

语言更顺不能抵消上述错误。
