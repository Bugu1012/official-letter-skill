# 样例索引使用说明



### url 字段约定

- 网络来源：填完整 URL（如 `https://www.gov.cn/...`）
- 本地文件：填 `local:` + 相对于技能根目录的路径（如 `local:征求意见函/MEE_xxx.txt`）

## 二、字段说明

| 字段 | 说明 |
|---|---|
| title | 函件标题 |
| url | 全文 URL |
| source | 来源（NDRC-提案答复函 / NDRC-人大代表建议复文） |
| type | 函类型 |

## 三、使用原则

- 只借鉴公开样例的结构、层级、句式。
- 不复制样例中的具体事实、数据、项目、地名、人名或政策结论。
- 优先使用标题与当前任务类型匹配的样例。
- 索引以答复函为主，其他类型函的结构学习依赖规则推导和 KaguraNanaga 示例。
