# 机关制度适配

## 一、为什么需要适配

GB/T 9704-2012 是推荐性标准，不是强制性标准。各机关可能有自己的版式制度。

## 二、常见差异

| 差异项 | 国标基线 | 常见变体 |
|---|---|---|
| 行距 | 28.95pt | 28pt / 29pt / 30pt |
| 正文字体 | 仿宋_GB2312 | 仿宋 / 方正仿宋 |
| 标题字体 | 方正小标宋简体 | 小标宋 / 华文中宋 |
| 函的发文字号 | X函〔20XX〕X号 | X办函 / X委函 / 其他代字 |
| 附注格式 | 左空2字加圆括号 | 部分机关不加圆括号 |
| 武文线 | 上粗下细双线 | 部分机关用等粗双线 |

## 三、适配流程

1. 起草前询问用户："贵机关是否有自己的公文版式制度？"
2. 如有，记录到事由台账的"机关制度"字段。
3. 起草时按机关制度覆盖国标基线。
4. 审查时按机关制度检查，不按国标基线报偏差。

## 四、质询式澄清

不确定时问："贵机关函件的发文字号代字是什么？行距是否有特殊规定？"

不因普通小差异反复打断用户。
