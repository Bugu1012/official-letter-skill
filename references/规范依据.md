# 规范依据

## 一、《党政机关公文处理工作条例》

中办发〔2012〕14号，2012年7月1日起施行。

### 第八条第十四项（函的定义）

> 函。适用于不相隶属机关之间商洽工作、询问和答复问题、请求批准和答复审批事项。

### 第九条（公文格式）

> 公文一般由份号、密级和保密期限、紧急程度、发文机关标志、发文字号、签发人、标题、主送机关、正文、附件说明、发文机关署名、成文日期、印章、附注、附件、抄送机关、印发机关和印发日期等要素组成。

### 使用边界

- 本技能以条例为文种适用和要素组成的最高依据。
- 条例未规定的格式细节（字体字号、行距、页边距）以 GB/T 9704-2012 为基线。
- 各机关可能有自己的版式制度，以本机关现行制度为准。

## 二、GB/T 9704-2012《党政机关公文格式》

### 信函式格式（函专用）

| 要素 | 信函式规格 |
|---|---|
| 发文机关标志 | 发文机关全称或规范化简称，不加"文件"二字，居中排布，上边缘至上页边距 30mm，推荐使用红色小标宋体字 |
| 红色分隔线 | 武文线（上粗下细双线），距发文机关标志下边缘 4mm |
| 发文字号 | 顶格居版心右边缘编排在第一条红色双线下 |
| 标题 | 居中，2 号小标宋体 |
| 主送机关 | 标题下空一行，顶格，3 号仿宋体 |
| 正文 | 3 号仿宋体，首行缩进 2 字符，行距固定值 28.95pt |
| 页码 | 首页不显示页码，从第 2 页起编 |

### 与文件式格式的差异

| 要素 | 信函式（函） | 文件式（通知/报告等） |
|---|---|---|
| 发文机关标志 | 机关名，不加"文件" | 机关名 + "文件" |
| 红色分隔线 | 武文线（双线） | 单线 |
| 发文字号位置 | 第一条双线下右端 | 版头下方居中或左端 |
| 首页页码 | 不显示 | 显示 |

### 通用格式参数（引用公文格式修订.skill）

- 纸张：A4（210mm × 297mm）
- 页边距：上 37mm / 下 35mm / 左 28mm / 右 26mm
- 版心：156mm × 225mm
- 每页 22 行，每行 28 字
- 行距：固定值 28.95pt（579 twips）
- 首行缩进：2 字符（32pt）

## 三、现行有效性

GB/T 9704-2012 经 2025-05-30 复审继续有效（来源：全国标准信息公共服务平台）。

## 四、使用原则

- 日常起草和审查不加载 PDF 全文。
- references/ 中的规则文件从标准中提取关键参数，标注对应条款号。
- 遇到 references/ 未覆盖的边缘规则时，查阅标准原文确认。
- 各机关现行制度优先于 GB/T 9704-2012 基线。
