# 函审查清单

> 逐项审查模板。审查时按顺序检查，每项标注 ✓/✗/N/A。

## 一、文种审查

- [ ] 是否确实应使用函（非请示/通知/报告/批复）
- [ ] 隶属关系是否正确判断
- [ ] 函类型是否正确（14 种之一）

## 二、结构审查

- [ ] 三段式完整（缘由→事项→结语）
- [ ] 一函一事
- [ ] 复函是否引用来函标题和字号
- [ ] 答复是否结论置前
- [ ] 征求意见函是否写明反馈时限（定向型：'请于X日前反馈'；公开型：'征求意见截止时间为X'）
- [ ] 征求意见函类型是否正确（定向型有主送+逾期条款；公开型无逾期条款、用'均可提出'）
- [ ] 协调函是否逐单位列明分工
- [ ] 协办函是否写明协办范围

## 三、要素审查

- [ ] 标题格式正确（关于〔事项〕的函/复函）
- [ ] 主送机关完整、顶格、全角冒号
- [ ] 落款完整（发文机关+日期）
- [ ] 附注联系人（默认保留）
- [ ] 附件说明（如有附件）

## 四、语气审查

- [ ] 平行文语气（无命令/卑微措辞）
- [ ] 称谓正确（贵单位/你单位/您）
- [ ] 结语与函类型匹配
- [ ] 无禁用措辞

## 五、内容审查

- [ ] 请求事项具体可执行
- [ ] 数据/文件号有来源
- [ ] 零编造
- [ ] 篇幅适当

## 六、AI 痕迹审查

- [ ] 无成组 AI 痕迹簇
- [ ] 无万能开头/结尾
- [ ] 无三连套话
- [ ] 无意义膨胀/虚假深度

## 七、格式审查

- [ ] 信函式版头（非文件式）
- [ ] 武文线（双线）
- [ ] 字体字号正确
- [ ] 行距 28.95pt
- [ ] 首行缩进 2 字符

## 八、评分

按 `references/三关键词量化评估.md` 打分。总分 ≥ 70 通过。
