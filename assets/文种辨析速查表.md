# 文种辨析速查表

> 快速判断是否应使用函。

## 判断流程

```
对象是上级（有隶属关系）？
  ├─ 是 → 请求批准？ → 请示
  │       汇报工作？ → 报告
  └─ 否 → 对象是下级（有隶属关系）？
      ├─ 是 → 部署工作？ → 通知
      │       答复请示？ → 批复
      └─ 否 → 不相隶属 → 函 ✓
```

## 速查表

| 你想做的事 | 对象关系 | 正确文种 | 常见误用 |
|---|---|---|---|
| 请求批准 | 有隶属→上级 | 请示 | — |
| 请求批准 | 无隶属→主管部门 | **请批函** | 误用请示 |
| 汇报工作 | 有隶属→上级 | 报告 | — |
| 通报情况 | 有隶属→下级 | 通知 | — |
| 通报情况 | 无隶属 | **告知函** | 误用通知 |
| 答复请示 | 有隶属→下级 | 批复 | — |
| 答复来函 | 无隶属 | **复函** | 误用批复 |
| 协商工作 | 无隶属 | **商洽函** | — |
| 征求意见 | 无隶属 | **征求意见函** | 误用通知 |
| 征求意见 | 有隶属→下级 | 通知 | — |
| 协调多方 | 无隶属/混合 | **协调函** | — |
| 请协办 | 无隶属 | **协办函** | — |
| 转办事项 | 无隶属 | **转办函** | — |
| 催促办理 | 无隶属 | **催办函** | — |
| 邀请参加 | 无隶属 | **邀请函** | — |
| 答复提案 | 无隶属（委员） | **提案答复函** | — |

## 核心原则

**有无隶属关系**是判断函 vs 非函的唯一标准。不确定时问用户。
