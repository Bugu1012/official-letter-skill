# 函起草模板

> 14 种函的起草模板。将〔占位符〕替换为实际内容。

---

## 1. 商洽函

```
关于〔事项〕的函

〔主送机关〕：

为〔目的〕，现商请贵单位协助〔事项〕。

〔协商事项分条列述〕

请予支持为盼。

（联系人：〔姓名〕；电话：〔电话〕）

〔发文机关署名〕
〔成文日期〕
```

## 2. 询问函

```
关于〔询问事项〕的函

一、〔问题一〕
二、〔问题二〕

请贵单位于〔日期〕前函复。

（联系人：〔姓名〕；电话：〔电话〕）

〔成文日期〕
```

## 5. 征求意见函

> 详细双型模板见 ssets/征求意见函模板.md。此处仅列骨架。

**定向型**（向特定机关）：
```
关于征求《〔文件名称〕（征求意见稿）》意见的函

〔主送机关〕：

为〔目的〕，我局/委起草了《〔文件名称〕（征求意见稿）》。现征求贵单位意见，请于〔日期〕前反馈。逾期未反馈的，视为无意见。

附件：1.《〔文件名称〕（征求意见稿）》

（联系人：〔姓名〕；电话：〔电话〕；邮箱：〔邮箱〕）

〔发文机关署名〕
〔成文日期〕
```

**公开型**（向社会公众）：
```
关于公开征求《〔文件名称〕（征求意见稿）》意见的函

为〔目的〕，我部组织〔起草/修订〕了《〔文件名称〕（征求意见稿）》，现公开征求意见。

各机关团体、企事业单位和个人均可提出意见和建议。有关意见请书面反馈我部，电子版材料请同时发至联系人邮箱。征求意见截止时间为〔日期〕。

联系人：〔司局〕 〔姓名〕  电话：〔号码〕  邮箱：〔邮箱〕

附件：〔文件名称〕（征求意见稿）

〔发文机关署名〕
〔成文日期〕
```
