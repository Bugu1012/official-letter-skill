# 征求意见函采集指南

> 用途：突破政府网站 JavaScript 渲染限制，手动采集征求意见函公开样例，补齐索引缺口。
> 产出：追加到 `assets/真实公开样例索引.csv`，type 列填 `征求意见函`。
> 目标：合计 30+ 篇，覆盖 5 个以上部委来源。

---

## 一、为什么必须手动

经实测，以下部委的征求意见列表页**全部使用 JavaScript 动态渲染**，HTTP 直接请求只能拿到空壳页面（无列表数据）：

| 部委 | 列表页 URL | 实测结果 |
|---|---|---|
| 生态环境部 MEE | mee.gov.cn/xxgk2018/xxgk/xxgk06/ | 30KB 空壳，无列表 |
| 司法部 MOJ | moj.gov.cn/pub/sfbgw/lfyjzj/ | 128 字节重定向 |
| 市场监管总局 SAMR | samr.gov.cn/hd/zjdc/ | 4.7KB 无数据 |
| 住建部 MOHURD | mohurd.gov.cn/gongkai/fdzdgknr/zqyj/ | 5.3KB 无列表 |

因此自动爬虫不可行。**但浏览器渲染完成后，DOM 里数据是齐全的**，可用控制台脚本一键提取。本指南走"浏览器渲染 + 控制台脚本"路线，零依赖、无需装环境。

## 三、操作步骤

### 步骤 1：打开列表页并等待渲染

1. 用 Chrome / Edge 打开上表任一列表页。
2. **等待 3-5 秒**，直到页面列表完全显示（看到一条条征求意见标题）。
3. 如有分页，翻到每一页都等待渲染（或滚动加载到底）。

### 步骤 2：在列表页运行提取脚本

按 `F12` 打开开发者工具 → 切到 `Console` 标签 → 粘贴运行**脚本 1**：

```javascript
// 脚本1：列表页提取（在已渲染的列表页 console 运行）
(function () {
  var rows = [];
  var seen = {};
  document.querySelectorAll('a').forEach(function (a) {
    var t = (a.textContent || '').trim();
    var h = a.href || '';
    // 筛选：标题含"征求"，且是正文页链接
    if (t.length >= 8 && /征求/.test(t) && /\.(s?html?)$/i.test(h) && !seen[h]) {
      seen[h] = 1;
      rows.push({ title: t, url: h });
    }
  });
  // 预览
  console.table(rows);
  // 生成 TSV 并复制到剪贴板
  var tsv = rows.map(function (r) { return r.title + '\t' + r.url; }).join('\n');
  var src = location.hostname.replace('www.', '').split('.')[0].toUpperCase() + '-征求意见函';
  var csv = rows.map(function (r) {
    return '"' + r.title.replace(/"/g, '""') + '","' + r.url + '","' + src + '","征求意见函"';
  }).join('\n');
  if (navigator.clipboard) {
    navigator.clipboard.writeText(csv).then(function () {
      console.log('已复制 ' + rows.length + ' 行 CSV 到剪贴板（含 title,url,source,type）。直接粘贴到 CSV 文件末尾即可。');
    });
  } else {
    console.log('剪贴板不可用，请手动复制下方 TSV：\n' + tsv);
  }
  return rows.length;
})();
```

运行后：
- `console.table` 会预览提取到的标题和链接，**先肉眼检查**是否都是征求意见函（剔除误抓的导航/无关链接）。
- 控制台会提示"已复制 N 行 CSV 到剪贴板"。

### 步骤 3：粘贴到索引文件

打开 `assets/真实公开样例索引.csv`，**滚动到末尾**，粘贴剪贴板内容（不要覆盖表头，不要重复粘贴表头行）。保存。

### 步骤 4：逐篇核验正文（抽查）

对每个来源**抽查 3-5 篇**，打开正文页确认它确实是"征求意见函"而非"征求意见采纳情况反馈"。运行**脚本 2** 提取元数据辅助判断：

```javascript
// 脚本2：单篇正文页元数据提取（在正文页 console 运行）
(function () {
  var body = document.body.innerText || '';
  var wh = (body.match(/[A-Za-z\u4e00-\u9fa5]+〔\d{4}〕\d+号/) || [''])[0];
  var hasDeadline = /于.{0,6}(年|月|日).{0,4}前.{0,6}(反馈|函复|意见)/.test(body) || /逾期.{0,6}(视为|无意见)/.test(body);
  var hasDraft = /征求意见稿/.test(body);
  var kind = /采纳情况|反馈情况|意见采纳/.test(document.title + body.slice(0, 200)) ? '征求意见反馈(复函类)' : '征求意见函';
  console.log(JSON.stringify({
    title: document.title.replace(/\s*[-_].*$/, '').trim(),
    wenhao: wh,
    has_feedback_deadline: hasDeadline,
    has_draft_attachment: hasDraft,
    judged_type: kind
  }, null, 2));
})();
```

判断标准：
- `judged_type = 征求意见函` 且 `has_feedback_deadline = true` → **合格样本**，保留。
- `judged_type = 征求意见反馈(复函类)` → 这是"反馈类复函"，**改 type 为 `征求意见反馈`** 后保留（可作为复函结构样本）。
- 既无反馈时限又无征求意见稿痕迹 → 疑似误抓，**剔除**。

### 步骤 5：翻页采集

回到列表页，点"下一页"，等待渲染，重复步骤 2-3，直到该来源采够 5-10 篇或翻完。

## 四、CSV 字段规范

追加行必须与现有索引列对齐（4 列，UTF-8，双引号包裹）：

```
"title","url","source","type"
```

| 字段 | 取值 |
|---|---|
| title | 函件标题，去掉网站后缀 |
| url | 正文页完整 URL |
| source | `部委缩写-征求意见函`，如 `MEE-征求意见函` |
| type | `征求意见函` 或 `征求意见反馈` |

去重：以 url 为准，已存在的 url 不再追加。

---

## 五、质量筛选标准

合格征求意见函应满足（至少 3 项）：

- [ ] 标题含"征求"+"意见"
- [ ] 正文有反馈时限（"于X年X月X日前反馈"）
- [ ] 正文有"逾期未反馈视为无意见"或等价表述
- [ ] 附件含《……（征求意见稿）》和起草说明
- [ ] 主送为平行/不相隶属机关序列

## 七、常见问题

**Q1：脚本 1 提取到 0 条？**
列表项可能不用 `<a>` 而是 `<li>` 包裹或点击事件加载。改用：把 `document.querySelectorAll('a')` 换成 `document.querySelectorAll('li a, .list a, .u-list a, td a')` 再试；或检查 Network 面板看列表数据来自哪个 XHR 接口，直接复制该接口 JSON。

**Q2：剪贴板复制失败？**
在非 https 或文件协议下 `navigator.clipboard` 可能不可用。改用脚本末尾的 TSV 输出手动复制，或临时在 DevTools 设置里勾选"允许剪贴板"。

**Q3：网站改版 URL 失效？**
到部委官网首页搜索框搜"征求意见"，进入栏目页后用脚本 1 提取，URL 不影响脚本逻辑。

**Q4：能否用 Selenium/Playwright 自动化？**
可以，但需本地装 Python + 浏览器驱动，违背本指南"零依赖手动"定位。若采集量大（>100 篇）再考虑，脚本 1/2 的逻辑可直接移植为 `page.evaluate()`。
