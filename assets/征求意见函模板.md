# 征求意见函模板

> 基于 8 篇真实公开征求意见函样例（生态环境部、国家卫健委、食标秘委）归纳。
> 征求意见函分**定向型**（向特定机关）和**公开型**（向社会公众）两种，结构有差异。

---

## 一、定向征求意见函模板

适用：向特定不相隶属机关征求对文件/方案的意见。

```
〔发文机关〕关于征求《〔文件名称〕（征求意见稿）》意见的函

〔主送机关一〕、〔主送机关二〕：

为〔目的〕，根据〔依据〕，我部/局/委组织起草了《〔文件名称〕（征求意见稿）》。现征求贵单位意见，请研究后于〔具体日期〕前将修改意见反馈我部/局/委。逾期未反馈的，视为无意见。

反馈意见请注明联系人及联系方式。如无修改意见，亦请函复确认。

附件：1.《〔文件名称〕（征求意见稿）》
      2.《〔文件名称〕》起草说明（如有）

（联系人：〔姓名〕；电话：〔号码〕；邮箱：〔邮箱〕）

〔发文机关署名〕
〔成文日期〕
```

**结构特征**：主送明确 → 依据+目的 → "现征求贵单位意见" → 时限+逾期条款 → 联系人 → 附件。正文通常 1-2 段，无需分条。

---

## 二、公开征求意见函模板

适用：面向社会公众公开征求意见（常见于部委规章/标准/规划制定）。

```
关于公开征求《〔文件名称〕（修订征求意见稿）》意见的函

为〔目的/贯彻精神〕，〔简述前期工作〕，我部组织〔起草/修订〕了《〔文件名称〕（征求意见稿）》，现公开征求意见。征求意见稿及其编制说明可登录〔网站〕"〔栏目〕"检索查阅。

各机关团体、企事业单位和个人均可提出意见和建议。有关意见请书面反馈我部，电子版材料请同时发至联系人邮箱。征求意见截止时间为〔具体日期〕。

联系人：〔司局〕 〔姓名〕
电话：〔号码〕
邮箱：〔邮箱〕
地址：〔通信地址〕

附件：〔文件名称〕（征求意见稿）

〔发文机关署名〕
〔成文日期〕
```

**结构特征**：无明确主送（或"各有关单位："）→ 依据+目的+"现公开征求意见" → "各机关团体……均可提出" → 反馈方式+截止时间 → 联系人信息块 → 附件。无"逾期视为无意见"条款。

---

## 三、两型对比

| 要素 | 定向型 | 公开型 |
|---|---|---|
| 主送 | 明确列出机关名称 | 无/泛指"各有关单位" |
| 核心动词 | "现征求贵单位意见" | "现公开征求意见"/"现向社会公开征求意见" |
| 逾期条款 | 必写"逾期未反馈视为无意见" | 不写 |
| 反馈主体 | "贵单位" | "各机关团体、企事业单位和个人" |
| 结语 | "请研究后函复"/"亦请函复确认" | 无专门结语，或"感谢支持！" |
| 附件 | 征求意见稿+起草说明（建议） | 征求意见稿（编制说明可上网查阅） |
| 篇幅 | 1-2 段 | 1-3 段 |

---

## 三-b、混合型说明

实践中存在**混合型**：主送"各有关单位"（定向形式）但使用"现公开征求意见"措辞（公开语言），如食品安全国家标准审评委员会秘书处的立项征求意见函。此类函件：
- 有明确主送（"各有关单位："）
- 使用"公开征求意见"动词
- 有具体反馈截止日期
- 通常**不写**"逾期视为无意见"
- 反馈方式为"书面反馈秘书处"

处理规则：按**公开型**模板起草，但保留主送称谓。不必强归某一型。

---

## 四、必备要素检查

- [ ] 标题含"征求意见"和文件名称
- [ ] 反馈时限明确（具体日期，非"尽快"）
- [ ] 反馈方式明确（书面/邮件/传真/在线系统）
- [ ] 联系人信息完整（姓名+电话+邮箱）
- [ ] 附件含征求意见稿
- [ ] 定向型：主送机关完整 + 逾期条款
- [ ] 公开型："均可提出"表述 + 查阅途径

## 五、常见错误

| 错误 | 修正 |
|---|---|
| 未写反馈时限 | 必须写明具体日期 |
| 定向型漏写"逾期视为无意见" | 必须写明 |
| 公开型误写"逾期视为无意见" | 公开型不写此条款 |
| 用"请批示"结语 | 改为"请研究后函复"或无结语 |
| 向不相隶属机关用通知征求意见 | 改为征求意见函 |
| 反馈方式仅一种 | 建议提供书面+邮件（公开型可加在线系统） |
| 附件缺征求意见稿 | 必须附（或注明网上查阅途径） |
| 公开型用"贵单位" | 改为"各机关团体、企事业单位和个人" |
