# 结语速查表

> 14 种函的规范结语和禁用结语。

| # | 函类型 | 规范结语 | 禁用结语 |
|---|---|---|---|
| 1 | 商洽函 | 请予支持 / 请予协助 / 请研究函复 / 盼复 / 特此函商 | 请批示 / 请批准 |
| 2 | 询问函 | 请函复 / 请研究后函告 / 盼复 / 请予函复为盼 | 请批示 / 特此报告 |
| 3 | 请批函 | 请予审批 / 请予批准 / 妥否请函复 / 请予审批为盼 | 请批示 / 当否请批示 |
| 4 | 告知函 | 特此函告 / 特此函达 / 专此函达 | 特此通知 / 请函复 |
| 5 | 征求意见函（定向） | 请于X日前反馈 / 逾期未反馈视为无意见 / 请研究后函复 | 请批示 |
| 5b | 征求意见函（公开） | 无专门结语（以联系人块收束）/ 感谢支持！ | 请批示 / 逾期视为无意见 |
| 6 | 邀请函 | 敬请莅临 / 恭请参加 / 敬请拨冗出席 / 盼复 | 请遵照执行 |
| 7 | 催办函 | 请抓紧办理 / 请尽快函复 / 如已办理请忽略本函 | 请遵照执行 / 务必 / 必须 |
| 8 | 协调函 | 请按分工落实 / 请于X日前反馈 / 特此函商 / 请予支持配合 | 请遵照执行 |
| 9 | 协办/协助函 | 请予协助为盼 / 请于X日前将协办结果函告 / 请予支持协助 | 请遵照执行 |
| 10 | 一般答复函 | 特此函复 / 此复 / 专此函复 | 特此通知 / 此致敬礼 |
| 11 | 批准函 | 特此函复 / 此复 | 此致敬礼 |
| 12 | 提案答复函 | 感谢您对……的关心和支持 / 特此函复 | 特此通知 |
| 13 | 建议答复函 | 感谢您对……的关心和支持 / 特此函复 | 特此通知 |
| 14 | 转办函 | 请办理后函告结果 / 特此函达 / 请抓紧办理并函告结果 | 请遵照执行 |

## 发函 vs 复函结语区分

| 方向 | 常用结语 |
|---|---|
| 发函（去函） | 请予支持 / 盼复 / 特此函告 / 妥否请函复 |
| 复函（回函） | 特此函复 / 此复 / 感谢关心和支持 |
