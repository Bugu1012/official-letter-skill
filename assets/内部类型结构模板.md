# 内部类型结构模板

> 适用：9 种公开样例不足的函类型（询问函、请批函、告知函、催办函、邀请函、转办函、征求意见函、协调函、协办/协助函）
> 说明：以下模板基于 GB/T 9704-2012 + zhaohui-yang 函 spec + KaguraNanaga 示例 + 公文写作教科书推导，标注为"规则推导模板"。实际使用时需根据本机关惯例调整。
> 使用方式：将〔占位符〕替换为实际内容，删除不需要的段落。

---

## 一、询问函模板

```
〔发文机关〕关于〔询问事项〕的函

〔主送机关〕：

因〔工作需要/业务需要〕，现就〔具体事项〕向贵单位函询如下：

一、〔第一个问题〕
〔具体说明需要了解的内容，包括时间范围、数据口径、涉及对象等〕

二、〔第二个问题〕
〔具体说明〕

三、〔第三个问题，如有〕
〔具体说明〕

请贵单位于〔日期〕前将有关情况函复我局/厅/委。

（联系人：〔姓名〕；电话：〔固定电话〕，〔手机号〕）

〔发文机关署名〕
〔成文日期〕
```

**结构要素**：起笔说明询问原因；正文问题列表，每个问题必须具体；结语"请函复""盼复"；附注联系人。
**语气**：礼貌直接，不泛泛而问。
**禁用**："请批示""特此报告"、问题模糊。

## 二、请批函模板

```
〔发文机关〕关于〔请求批准事项〕的函

〔主送机关〕：

根据〔法规/文件/会议决定〕，〔简述背景〕。现就〔具体事项〕函请贵单位审批。

一、请求事项
〔具体说明请求批准的内容，包括范围、数量、金额等〕

二、理由和依据
〔说明为什么需要批准，引用相关法规条款或政策依据〕

三、相关条件
〔如有前置条件或配套措施，在此说明〕

妥否，请函复。

附件：〔附件名称，如有〕

（联系人：〔姓名〕；电话：〔固定电话〕，〔手机号〕）

〔发文机关署名〕
〔成文日期〕
```

**结构要素**：起笔引用依据+背景；正文请求事项+理由+条件；结语"请予审批""妥否，请函复"。
**语气**：礼貌但明确。
**禁用**："妥否，请批示""当否，请批示"。
**与请示区别**：请批函→无隶属关系的主管部门；请示→有隶属关系的上级。

## 三、告知函模板

```
〔发文机关〕关于〔告知事项〕的函

〔主送机关〕：

因〔原因/背景〕，现将有关事项函告如下：

一、〔告知事项一〕
〔具体说明〕

二、〔告知事项二〕
〔具体说明〕

特此函告。

（联系人：〔姓名〕；电话：〔固定电话〕，〔手机号〕）

〔发文机关署名〕
〔成文日期〕
```

**结构要素**：起笔说明原因；正文通报事项；结语"特此函告""特此函达"。
**语气**：平和告知，不期待回复。
**禁用**："请函复""盼复""特此通知"。

## 四、催办函模板

```
〔发文机关〕关于催促办理〔事项〕的函

〔主送机关〕：

关于〔事项〕，我局/厅/委曾于〔日期〕致函贵单位（〔发文字号〕），〔简述此前函件内容〕。截至目前，尚未收到贵单位的回复/办理结果。

鉴于〔催促理由〕，请贵单位抓紧办理，并于〔新时限〕前将办理情况函告我局/厅/委。

如已办理完毕，请忽略本函。

（联系人：〔姓名〕；电话：〔固定电话〕，〔手机号〕）

〔发文机关署名〕
〔成文日期〕
```

**结构要素**：起笔引述此前函件（日期+字号+摘要）；正文未收到回复+催促理由+新时限；结语"请抓紧办理"。
**语气**：礼貌但紧迫。
**禁用**："请遵照执行""务必""必须"。

## 五、邀请函模板

```
〔发文机关〕关于邀请参加〔活动名称〕的函

〔主送机关〕：

兹定于〔日期〕在〔地点〕举办〔活动名称〕。〔简要说明活动目的〕。

诚邀贵单位〔参加方式〕。现将有关事项函告如下：

一、活动时间：〔具体日期和时间〕
二、活动地点：〔详细地址〕
三、参加人员：〔人数/职务要求/名单报送方式〕
四、其他事项：〔食宿/交通/材料准备等〕

请于〔日期〕前将参会回执反馈我局/厅/委。

（联系人：〔姓名〕；电话：〔固定电话〕，〔手机号〕）

〔发文机关署名〕
〔成文日期〕
```

**结构要素**：起笔时间+地点+活动名称；正文活动说明+参加要求；结语"敬请莅临""恭请参加"。
**语气**：礼貌热情但不空泛。
**禁用**："请遵照执行"、空泛意义描述。

## 六、转办函/交办函模板

```
〔发文机关〕关于转送〔事项〕的函

〔主送机关〕：

现将〔来源〕转来的〔事项名称〕转送贵单位办理。

一、转办事项：〔具体内容〕
二、办理要求：〔标准/时限/反馈方式〕
三、注意事项：〔特殊要求或限制条件〕

请贵单位办理后将结果函告我局/厅/委。

附件：〔转办材料名称〕

（联系人：〔姓名〕；电话：〔固定电话〕，〔手机号〕）

〔发文机关署名〕
〔成文日期〕
```

**结构要素**：起笔说明来源；正文转办事项+办理要求；结语"请办理后函告结果"。
**语气**：明确但不命令。
**禁用**："请遵照执行"。

## 七、征求意见函模板

```
〔发文机关〕关于征求《〔文件名称〕（征求意见稿）》意见的函

〔主送机关〕：

为〔目的/背景〕，我局/厅/委起草了《〔文件名称〕（征求意见稿）》。现征求贵单位意见，请研究后于〔日期〕前将修改意见反馈我局/厅/委。逾期未反馈的，视为无意见。

一、征求意见的背景：〔简述原因〕
二、征求意见的重点：〔如有重点关注内容〕
三、反馈方式：〔书面/邮件/传真，注明接收地址和联系人〕

附件：1.《〔文件名称〕（征求意见稿）》
      2. 起草说明

（联系人：〔姓名〕；电话：〔固定电话〕，〔手机号〕；邮箱：〔邮箱〕）

〔发文机关署名〕
〔成文日期〕
```

**结构要素**：起笔说明文件名称和目的；正文背景+重点+反馈方式；结语必须含反馈时限+"逾期未反馈视为无意见"；附件征求意见稿+起草说明。
**语气**：平等征询。
**禁用**："请批示"、不写反馈时限。

## 八、协调函模板

```
〔发文机关/牵头单位〕关于协调〔事项〕的函

〔主送机关一〕、〔主送机关二〕、〔主送机关三〕：

为〔目的/背景〕，根据〔依据/会议决定/上级要求〕，现就〔协调事项〕函商各单位如下：

一、协调背景
〔简述需要协调的原因、涉及各方、当前进展或分歧〕

二、各方分工
（一）〔单位一〕负责〔具体任务〕，于〔时限〕前完成〔成果形态〕。
（二）〔单位二〕负责〔具体任务〕，于〔时限〕前完成〔成果形态〕。
（三）〔单位三〕负责〔具体任务〕，于〔时限〕前完成〔成果形态〕。

三、协调机制
〔如建立联席会议/定期通报/信息共享等机制，在此说明〕

四、反馈要求
请各单位于〔日期〕前将落实方案/意见反馈我局/厅/委。执行中的重要情况请及时通报。

（联系人：〔姓名〕；电话：〔固定电话〕，〔手机号〕）

〔发文机关署名〕
〔成文日期〕
```

**结构要素**：
- 起笔：说明协调目的和依据
- 正文：协调背景 + 各方分工（逐单位列明任务/时限/成果） + 协调机制 + 反馈要求
- 主送：通常 3 个以上单位，按从主到次排列
- 结语："请各单位按分工落实""请于〔日期〕前反馈"

**语气要求**：牵头方有一定的组织权威，但仍用"函商""请"而非命令语气。分工要明确到具体单位，不能用"各单位自行落实"。

**与商洽函的区别**：商洽函是双方平等协商，没有牵头方；协调函有牵头/组织方，协调多方行动，正文必须明确各方分工。

**禁用**：
- "请遵照执行"（命令语气）
- 分工模糊（如"请各单位配合"而不说明谁做什么）

## 九、协办/协助函模板

```
〔主办单位〕关于请协助办理〔事项〕的函

〔协办单位〕：

根据〔依据/工作安排〕，我局/厅/委正在办理〔主办事宜〕。因〔原因〕，需贵单位协助办理〔协办事项〕。现将有关事项函告如下：

一、主办事宜
〔简述主办事项的背景、目标和当前进展〕

二、协办请求
请贵单位协助办理以下事项：
（一）〔协办内容一〕，请于〔时限〕前完成。
（二）〔协办内容二〕，请于〔时限〕前完成。

三、协办范围
〔明确协办的边界，避免协办单位承担超出范围的工作〕

四、反馈方式
请贵单位于〔日期〕前将协办结果/材料函告我局/厅/委。

（联系人：〔姓名〕；电话：〔固定电话〕，〔手机号〕）

〔发文机关署名〕
〔成文日期〕
```

**结构要素**：
- 起笔：说明主办事宜和需要协办的原因
- 正文：主办事宜 + 协办请求（逐条列明） + 协办范围 + 反馈方式
- 结语："请予协助""请于〔日期〕前将协办结果函告"

**语气要求**：礼貌但具体。因为有明确的主办-协办关系，协办请求应比商洽函更具体（写明协办范围和时限）。

**与商洽函的区别**：商洽函是双方协商一个共同事项；协办函是主办单位请协办单位配合办理主办事宜的一部分，存在明确的主办-协办关系。

**与转办函的区别**：转办函是将事项整体转交对方办理；协办函是主办事项仍在主办单位，只请对方协助其中一部分。

**禁用**：
- "请遵照执行"（命令语气）
- 协办范围不清（如"请协助办理有关事项"而不说明什么事项）

## 使用原则

1. 占位符必须替换，不得保留发出。
2. 按需删减段落，但必备要素不可省略。
3. 语气与函类型匹配。
4. 一函一事。
5. 附注默认保留。
